Star Wars Zero Company

Zero Company Mod Studio

A mod editor that reads the game's own files, copies what is already in there, and writes a mod the game loads on startup. No Unreal Engine, no coding.

Download the latest release

Windows 64-bit · unzip and run ZeroCompanyModStudio.exe · no installer

What it makes

Armour and clothing from any part in the game, including gear hidden from the menu. Your own models, imported from FBX, with a Blender add-on that browses the game from inside Blender. Weapons duplicated whole onto a shelf of their own in the Armoury. Balance changes to any weapon. Classes built from any of the game's 826 abilities. And battle droids as recruits — a B1, B2 or BX who fights with his own animations, his own weapon and his own action points.

It can also change the game's own things rather than adding beside them: a replacement puts your model into the helmet everybody already wears, and the abilities browser opens all 826 of them with every number behind each one — and a warning on any the game works out somewhere else.

Everything you add is made by copying something the game already has, so a part you make behaves like a part the game shipped. The game's own files are never written to: a mod is a folder you can delete, replacements included.
